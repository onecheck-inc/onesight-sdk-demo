# OneS1ght SDK 데모

**OneS1ghtSDK**(실내 UWB·DL-TDoA 측위 iOS SDK)를 사용하는 데모 앱입니다.
고객사 앱이 SDK를 붙이는 형태를 그대로 보여줍니다.

실내에서 내 위치를 도면 위에 실시간으로 표시하고, 지정 구역에 진입하면
서버가 내려준 액션을 앱에서 처리합니다.

## 구성

```
oneS1ghtSdk/    데모 앱 (SwiftUI) — 도면 표시 · 실시간 위치 · 구역 진입 처리
```

SDK 자체는 이 저장소에 없습니다. **별도 저장소에서 배포**되며,
측위 → 존 진입/이탈 판정 → 서버 수집·이벤트 수신을 담당합니다.

## 시작하기

빌드·설치·사용 방법은 **적용 가이드(APPLY_GUIDE)** 를 따라 하세요. (약 5분)

> ⚠️ 실행에 필요한 세 가지는 저장소에 포함되어 있지 않습니다 —
> **SDK 접근 권한**, **키 파일(`secrets.sqlite`)**, **적용 가이드**.
> OneCheck 담당자가 계약 고객사에 별도로 전달합니다.

## 요구 사항

- Mac + Xcode 27 (베타)
- iPhone 12 이상 (UWB 지원) · iOS 27 이상
- 측위 앵커가 설치된 공간 (데모 존)

## 언어

한국어 · 日本語 · English (시스템 언어 자동, 그 외는 한국어)
